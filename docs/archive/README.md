# docs/archive — historical records

**The paths in these files are historical. Leave them as they are.**

Everything in this folder was written while the project lived at
`/home/muffin/Desktop/Nexus project`. On 18 Sep 2026 the project moved to
`/home/muffin/VibeCodeProjects/atrium`, with the crates under `crates/` and the
documents under `docs/` — so a path like
`/home/muffin/Desktop/Nexus project/snapshot` now reads
`/home/muffin/VibeCodeProjects/atrium/crates/snapshot`.

None of that has been rewritten here, deliberately. These are evidence files: the
commands quoted in them are the commands that were actually run, at the path that
actually existed at the time. Rewriting `cd "/home/muffin/Desktop/Nexus project/x"`
to the new location would make the record claim something that never happened, and
an evidence file that misstates its own commands is worth less than no file at all.
A reader who needs the current path should read `docs/STATUS.md` or the crate's own
`README.md`, not this folder.

The one exception is `delegation-briefs/`, whose instructions told a subagent to
write under the old path. Those are kept verbatim for the same reason — they are the
briefs as dispatched, and three phases were built from them successfully.
